# Perigo Mine EDA — Geochemistry & Environmental Tracer Analysis

Exploratory Data Analysis (EDA) of geochemistry and environmental tracer data for groundwater and stream water collected from the **Perigo Mine Site, Colorado (2024)**.

## Project Overview

This project investigates water chemistry and environmental tracers at the Perigo Mine site to understand groundwater-surface water interactions, contaminant transport, and hydrological processes at an abandoned mine site.

## Files

| File | Description |
|------|-------------|
| `Perigo_Mine_EDA.ipynb` | Main Jupyter Notebook with full EDA |
| `Perigo_Mine_clean.xlsx` | Cleaned consolidated dataset |

| `output *.png` | EDA output figures |

## Key Analyses

- Water chemistry characterization (major ions, pH, conductivity)
- Environmental tracer analysis (isotopes, age tracers)
- Groundwater-stream water mixing analysis
- Slug test hydraulic conductivity estimation
- Contaminant load estimation from streamflow data
- Geochemical visualization and interpretation

## Tools and Libraries

- Python: pandas, numpy, matplotlib, seaborn
- Jupyter Notebook
- Data sources: USGS / Colorado field sampling campaign (2024)
